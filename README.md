Exactly one word, 6 characters, that my ex would use to describe me: **Unread**. The message sent, the ticks turning blue, and then nothing — a phone status pretending to be a personality trait. The program reads the word from `entry.txt`, checks it rule by rule against the bounty gate (UTF-8, 1–24 characters, exactly one word, plain letters, no trailing space), and publishes it byte for byte to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
